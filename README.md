# Project Repository

## 🎨 Frontend (React)

The frontend of this application is built using **React.js**, providing a modern, responsive, and intuitive user experience for managing quality defects efficiently.

### 🚀 Key Highlights

* ⚡ **Dynamic UI with Real-Time Updates**
  Seamlessly reflects backend data changes without page reloads, ensuring up-to-date defect tracking.

* 🧭 **Structured Navigation**
  Clean layout with dedicated sections for:

  * Dashboard
  * Defects
  * Root Cause Analysis
  * Corrective Actions
  * CSV Export

* 📊 **Interactive Dashboard**

  * Visual overview of total, open, and closed defects
  * Highlights overdue actions
  * Displays defect distribution across statuses

* 📝 **Smart Defect Logging Interface**

  * User-friendly forms with validation
  * Dropdown-based selections for consistency
  * Error handling to prevent invalid submissions

* 🔍 **Advanced Filtering & Search**

  * Filter defects by status, severity, and area
  * Quick search for efficient defect management

* 🧠 **Root Cause Analysis (5-Why UI)**

  * Structured input fields for systematic analysis
  * Enforces completion before workflow progression

* ✅ **Corrective Action Tracking UI**

  * Add multiple actions per defect
  * Track progress
